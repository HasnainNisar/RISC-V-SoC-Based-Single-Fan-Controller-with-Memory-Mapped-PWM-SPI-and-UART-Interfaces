# RISC-V-SoC-Based-Single-Fan-Controller-with-Memory-Mapped-PWM-SPI-and-UART-Interfaces
A synthesizable RISC-V RV32I processor SoC architecture configured for autonomous cooling fan management via memory-mapped PWM, SPI, and UART blocks. Extensively verified using layered directed assembly test vectors, SystemVerilog Assertions (SVA), and a closed-loop UVM regression workspace.
